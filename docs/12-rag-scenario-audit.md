# RAG 场景审查与 GraphRAG-lite 增强方案

## 1. 审查结论

传统 RAG 的三个痛点不能用“再加几个 Top-K”解决。当前项目已经具备 Hybrid（关键词 + 向量 + RRF）、Query Rewrite、重排和 Parent-Child，但这些能力本质上仍然以切块为中心：它们能提高“找到相似片段”的概率，不能自动建立跨文档实体关系，也不能对全库内容做覆盖性归纳。

因此本阶段不把所有问题都强行送进图谱，而是先按问题形态分层：

| 问题场景 | 当前链路 | 当前结论 | GraphRAG-lite 策略 |
| --- | --- | --- | --- |
| 单事实定位（“年假多少天”） | 路由 -> Hybrid/RRF -> 重排 -> 引用回答 | 已能解决；图谱反而增加延迟 | 保持局部 Hybrid，图谱不介入 |
| 同文档上下文（“这段代码为何这样写”） | Parent-Child 扩展同章节相邻块 | 基本能解决；代码围栏和标题有保护 | 保持 Parent-Child，图谱只作辅助 |
| 多跳关系（“A 如何影响 B，经过哪些组件”） | Top-K 切块 + 相邻扩展 | 不能保证召回中间实体和跨文档证据 | 实体匹配 -> 一跳关系扩展 -> 原始切块 RRF 合并 |
| 跨文档关系（“方案 X 与故障 Y 的共同原因”） | 不理解实体共现和关系方向 | 容易得到相似但不相连的片段 | 关系边和切块关联提供候选，再由模型组织因果链 |
| 全局归纳（“整个知识库有哪些主题/趋势”） | 社区摘要匹配 -> 原始切块覆盖采样 | level 1 全局摘要提供跨社区导航，最终证据仍按文档覆盖展开 | 两层社区摘要 + 图谱重要实体覆盖，回答必须标注范围 |
| 切块边界实体断裂 | overlap + 同章节父上下文 | 只能缓解同一文档，跨文档仍断裂 | 实体/关系索引跨切块连接，引用仍定位到命中子块 |
| 无实体或歧义问题 | Query Router direct/memory/clarify/rag | 路由已能避免伪引用 | 图谱仅对 `rag` 且识别为关系/全局的问题启用 |

## 2. 三个痛点的验收定义

### 2.1 多跳推理

不能只看最终答案是否“像对的”，必须记录：命中的实体数、关系扩展数、进入生成上下文的唯一切块数，以及每条关系能否回指 `document:{id}:chunk:{ordinal}`。若图谱没有可回指证据，必须降级为资料不足，而不是生成猜测。

### 2.2 全局问题

全局模式的首要目标是覆盖，而不是相似度最高。当前实现先匹配 `graph_revision` 一致的 level 1/level 0
社区摘要，再展开其 `source_chunk_ids`；最终只返回可定位到原始文档切块的证据。评测至少记录文档
覆盖率、代表实体覆盖率、社区命中数、引用数量和总延迟。社区算法目前使用确定性的连通分量，
可选 LLM 抽取/摘要均有规则回退。

### 2.3 切块语义断裂

Parent-Child 负责同文档局部上下文，实体关系索引负责跨块连接。切块器仍必须保留标题、代码围栏和原始顺序；图谱只增加召回候选，不修改原始正文，也不能把关系文本当作无来源事实。

## 3. 本阶段实现边界

1. 入库 Worker 为每个活动文档建立实体、关系和 `chunk -> entity` 关联；重试和重切分必须幂等替换。
2. 关系查询使用一跳扩展，最多扩展到配置的实体/切块上限，防止图遍历导致 Prompt 膨胀。
3. 全局查询从不同文档和高频实体覆盖中选取代表切块，再交给受证据约束的 LLM 总结。
4. GraphRAG 候选与 Hybrid 候选使用 RRF 融合，图谱故障或没有实体命中时自动回退原有链路。
5. 诊断接口和 SSE trace 增加图谱模式、实体数、关系扩展数和图谱候选数；日志不记录正文。
6. 当前内置实体抽取器是保守的规则实现；显式图重建可切换 JSON 约束的 LLM 抽取器和社区摘要器，
   任一模型失败都回退到规则/确定性实现，不阻断入库。

## 4. 后续 GraphRAG 完整化路线

- 使用真实模型和标注集校准 LLM Entity/Relation Extractor 的置信度与成本。
- 将当前连通分量替换为 Leiden/Louvain 等社区算法，增加社区摘要向量索引和多层父子社区。
- 增加局部/全局评测集，比较 Baseline、Hybrid、GraphRAG-lite 和 Community Summary 的 Recall@K、MRR、文档覆盖率、拒答正确率和 P95 延迟。
- PostgreSQL 生产环境使用实体名称索引、关系方向索引和租户 RLS；图遍历设置超时、节点数和边数上限。
